Design a logic circuit, flip a switch, watch it settle.

A Java Swing application for building and simulating digital logic: place switches, gates and LEDs, wire them up, and signals propagate through any depth of combinational logic. It generates truth tables and flags short circuits. Built as a team object-oriented programming project.

Object-oriented structure

Every part is a Component

Each part implements its own evaluate(); gates share their Boolean logic through an abstract LogicGate. The simulation core has no Swing dependency, which is what makes it testable.

PackageContents
componentsComponent (abstract) → Switch, LED, VCC, Ground, LogicGate (abstract) → AND, OR, NOT, XOR, NAND, NOR, XNOR

How signals propagate

Iterate until nothing changes

Circuit.simulate() repeats one pass until no node changes state, which handles multi-level circuits without a topological sort.

01SourcesEvaluate switches, VCC, ground
02PropagateCopy each connection's source state to its destination
03GatesEvaluate every logic gate
04PropagatePush gate outputs along connections
05OutputsEvaluate LEDs
06Converged?Stop when a pass changes nothing
