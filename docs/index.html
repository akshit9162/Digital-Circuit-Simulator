Iterate until nothing changes

Circuit.simulate() grounds open inputs once, then repeats one pass until no node changes state, so a deep circuit needs no topological sort.

Built for combinational logic. A feedback loop stops after the component count plus two passes (at least five), settled or not.

  1. 1Evaluate the sources: switches, VCC, ground
  2. 2Carry every signal along its connection
  3. 3Evaluate every gate
  4. 4Carry the gate outputs
  5. 5Light the LEDs, then stop if nothing changed

Every part is a component

Each part overrides evaluate(); the gates share node setup and logic helpers through an abstract LogicGate.

Sources

Switch, VCC, Ground

Gates

AND, OR, NOT, XOR, NAND, NOR, XNOR

Outputs

LED

What it checks

  • VCC, or a closed switch, reaching ground through any chain of connections.
  • Two outputs driving one input high and low at once.
  • Truth tables for any circuit of switches and LEDs.

Run it

JDK 17 or newer. The tests run without a window; CI runs them on pushes to main and on pull requests. On Windows, run build_and_run.bat. Fixed along the way: multi-input gates once always built two inputs.

git clone https://github.com/akshit9162/Digital-Circuit-Simulator
cd Digital-Circuit-Simulator
make run     # compile and open the editor
make test    # 44/44 checks passed
